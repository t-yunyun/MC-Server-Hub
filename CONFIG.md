# 配置说明

本文档说明 `config.json` 中全部配置项。配置文件由项目根目录的 `config.json` 提供，可从模板复制生成：

```bash
# Windows
copy config.json.example config.json

# Linux / macOS
cp config.json.example config.json
```

## 必填与可选

配置项分两类，区别在于源码的读取方式：

- **必填项**：以 `CFG['KEY']` 方式读取，`config.json` 中缺失会直接抛出 `KeyError` 导致启动失败。
- **可选项**：以 `CFG.get('KEY', 默认值)` 方式读取，缺失时使用下表所列默认值，可安全省略。

从 `config.json.example` 复制而来的文件已包含全部配置项，无需手动增删。

---

## 一、服务与访问

| 配置项              | 类型      | 默认值                      | 必填  | 说明                                                      |
|:---------------- |:------- |:------------------------ |:---:|:------------------------------------------------------- |
| `HOST`           | String  | `0.0.0.0`                | 否   | 服务监听的主机地址。`0.0.0.0` 表示允许所有外部 IP 访问，本地调试可改为 `127.0.0.1`。 |
| `PORT`           | Integer | `5000`                   | 否   | 服务监听的端口号。若端口被占用或需修改，请在此处更改。                             |
| `SECRET_KEY`     | String  | `MC-Server-Hub-key-2026` | 是   | Flask 会话加密密钥，用于管理员登录状态保持。**部署前请务必修改为随机字符串**。            |
| `ADMIN_PASSWORD` | String  | `admin123`               | 是   | 后台管理员登录密码。**部署前请务必修改**。                                 |

## 二、巡检与数据存储

| 配置项              | 类型      | 默认值                         | 必填  | 说明                                                                     |
|:---------------- |:------- |:--------------------------- |:---:|:---------------------------------------------------------------------- |
| `CHECK_INTERVAL` | Integer | `60`                        | 是   | 后台自动巡检服务器的间隔时间（单位：秒）。不建议设置过低，以免被状态查询 API 限流。                           |
| `MAX_HISTORY`    | Integer | `120`                       | 是   | 服务器详情页状态图表保留的历史记录条数（按巡检间隔计算，120 条约等于近 2 小时数据）。                         |
| `MAX_API_LOGS`   | Integer | `50`                        | 是   | 服务器状态 API 请求日志的最大保留条数，超出后自动清理旧记录。                                      |
| `DATA_FILE`      | String  | `./data/data.json`          | 是   | 核心业务数据文件路径，存储服务器列表、资源列表及关联关系。                                          |
| `STATUS_FILE`    | String  | `./data/Server_status.json` | 是   | 服务器实时状态缓存文件，存储在线人数、延迟、MOTD 等巡检结果。                                      |
| `API_LOG_FILE`   | String  | `./data/api_response.json`  | 是   | API 请求日志存储文件，用于排查巡检失败问题。                                               |
| `UPLOAD_DIR`     | String  | `uploads`                   | 是   | 文件上传根目录。整合包将存储于 `{UPLOAD_DIR}/packs`，资源文件存储于 `{UPLOAD_DIR}/resources`。 |

## 三、界面显示

| 配置项                | 类型      | 默认值           | 必填  | 说明                                                                               |
|:------------------ |:------- |:------------- |:---:|:-------------------------------------------------------------------------------- |
| `FOOTER_FILE`      | String  | `footer.html` | 否   | 自定义页尾 HTML 文件路径（相对项目根目录）。文件存在时内容会注入大厅首页与管理后台底部；文件不存在则不渲染页尾，无需改代码。                |
| `HIDE_ADMIN_ENTRY` | Boolean | `fasle`       | 否   | 是否隐藏大厅首页导航栏的「管理员入口」按钮。`true` 时未登录访客看不到入口（仍可直接访问 `/admin` 登录）；已登录管理员始终显示「管理后台」按钮。 |

## 四、离线邮件告警

告警功能默认关闭（`ALERT_ENABLED: false`），关闭时巡检仅记录状态、不发送任何邮件，`SMTP_*` 各项可留空。

| 配置项                     | 类型      | 默认值     | 必填  | 说明                                                                                                                               |
|:----------------------- |:------- |:------- |:---:|:-------------------------------------------------------------------------------------------------------------------------------- |
| `ALERT_ENABLED`         | Boolean | `false` | 否   | 是否启用离线告警邮件功能。设为 `false` 时，巡检不会发送任何告警邮件，仅记录状态。                                                                                    |
| `ALERT_OFFLINE_MINUTES` | Integer | `60`    | 否   | 服务器离线多久后触发告警邮件（单位：分钟）。服务器级 `alert_offline_minutes` 字段可覆盖此全局值。                                                                    |
| `ALERT_REPEAT_MINUTES`  | Integer | `60`    | 否   | 重复告警间隔（单位：分钟）。首次告警后若服务器持续离线，每隔此间隔会再次发送告警。可在管理后台「全局告警设置」中修改，保存后立即生效并写入此文件。                                                        |
| `ALERT_BASE_URL`        | String  | 空       | 否   | 面板对外访问的基础地址（如 `http://your-domain:5001`），用于拼接告警邮件中的拒收链接 `/verify?id=&email=`。留空时自动使用 `http://127.0.0.1:{PORT}`。公网部署时请配置为外部可访问地址。 |
| `SMTP_HOST`             | String  | 空       | 否   | SMTP 服务器地址。常见：QQ 邮箱 `smtp.qq.com`、网易 `smtp.163.com`、Gmail `smtp.gmail.com`。                                                      |
| `SMTP_PORT`             | Integer | `465`   | 否   | SMTP 服务器端口。SSL 直连通常为 `465`，STARTTLS 通常为 `587`，需与 `SMTP_USE_SSL` 配套使用。                                                            |
| `SMTP_USER`             | String  | 空       | 否   | SMTP 登录账号（即发件邮箱地址），同时默认作为告警邮件的收件人之一。                                                                                             |
| `SMTP_PASSWORD`         | String  | 空       | 否   | SMTP 登录授权码（**不是邮箱登录密码**）。QQ/网易等邮箱需在设置中开启 SMTP 服务并生成授权码。**部署前请务必修改**。                                                             |
| `SMTP_FROM`             | String  | 空       | 否   | 实际显示的发件人地址。留空时默认使用 `SMTP_USER`。                                                                                                  |
| `SMTP_USE_SSL`          | Boolean | `true`  | 否   | 是否使用 SSL 直连。`true` 走 `SMTP_SSL`（建议端口 `465`），`false` 走 `SMTP` + `STARTTLS`（建议端口 `587`）。                                           |

- [ ] `ADMIN_PASSWORD` 已改为强密码
- [ ] 如启用邮件告警，`SMTP_PASSWORD` 已填入邮箱授权码（非登录密码）
- [ ] 如公网部署，`HOST` / `PORT` / `ALERT_BASE_URL` 已按实际访问地址配置
